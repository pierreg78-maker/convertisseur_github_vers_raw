# convertisseur_github_vers_raw
# GitHub → Raw Converter

Convertisseur ultra rapide d'URLs GitHub vers raw.githubusercontent.com  
Colle jusqu'à 25 liens, 1 clic, tout est copié dans le presse-papier.

### [🚀 Utiliser l'outil en ligne](https://pierreg78-maker.github.io/github-to-raw-converter/)

---

### Comment ça marche ?
GitHub affiche ça :  
`https://github.com/user/repo/blob/main/src/file.js`

Le navigateur a besoin de ça :  
`https://raw.githubusercontent.com/user/repo/main/src/file.js`

Ce script fait juste 2 remplacements : 
1. `github.com` → `raw.githubusercontent.com`
2. `/blob/` → `/`

### Fonctionnalités
- **Batch** : Traite jusqu'à 25 URLs à la fois
- **Copie auto** : Le résultat est directement dans ton presse-papier
- **Bouton Effacer** : Pour la sécurité, supprime tout en 1 clic
- **100% Local** : Rien n'est envoyé sur un serveur. Tout tourne dans ton navigateur.
- **Raccourci** : `Ctrl + Enter` pour convertir

### Installation / Déploiement
1. Fork ce repo
2. Va dans `Settings` > `Pages`
3. Source: `Deploy from a branch` > `main` > `/root`
4. Attends 1 min et ton site est en ligne
